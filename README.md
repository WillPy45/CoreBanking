# CoreBanking
Core banking is in continuous development, the system is designed to support:
- Creation of clients <br>
- Bank accounts in various currencies <br>
- Money transactions <br>
- Currency exchange with margins set by the bank <br>
- And more features <br>

This project need a refactor, I want to use technologies like Docker, Docker Compose, separate concerns in subprojects like Tests, Integration Tests, Domain, Infraestructure, Data, and more. And maybe implements a frontend, but the current concern is ensures that API is made in the correct way.
